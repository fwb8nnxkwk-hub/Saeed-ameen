دليل رفع المشروع على GitHub Pages (خاص باسم الريبو Saeed-ameen)

1) اذهب إلى حساب GitHub الخاص بك وادخل على الريبو: https://github.com/Saeeddous/Saeed-ameen
2) إذا لم تنشئ الريبو بعد، أنشئ مستودع جديد باسم **Saeed-ameen** (Public).
3) ارفع محتويات هذا المجلد إلى الريبو (ارفع جميع الملفات في root).
4) في الريبو، اذهب إلى Settings → Pages → Source: branch = main, folder = / (root). احفظ.
5) بعد ثوانٍ تظهر لك صفحة النشر: https://Saeeddous.github.io/Saeed-ameen/
6) افتح الرابط في Safari على الآيفون → زر المشاركة → Add to Home Screen
ملاحظات:
- الملفات تستخدم مسارات نسبية لضمان العمل داخل مجلد الريبو Saeed-ameen.
- إن واجهت أي خطأ، ارسل لي هنا "مشكلة رفع" وأعطيك خطوات تصحيح سريعة.
